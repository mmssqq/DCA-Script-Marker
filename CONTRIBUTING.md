# Contributing during the private beta

Thank you for helping test DCA Script Marker.

During the private beta, please submit bug reports, usability feedback, and
sanitized reproduction steps only. Do not submit pull requests or patches yet.
This temporary policy preserves the project's ability to offer a separately
licensed Mac App Store edition later.

Never attach a confidential script, DCA workbook, marked PDF, or review report
to a public issue. Use the fields in [BETA_FEEDBACK_TEMPLATE.md](BETA_FEEDBACK_TEMPLATE.md)
and share sanitized files only when you have permission.

A contributor policy will be published before outside code contributions are
accepted.
